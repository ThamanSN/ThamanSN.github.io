    ASCEND – Autonomous UAV System

    Event: IRoC-U 2026 (ISRO Robotics Challenge) | Concept Proposal Submitted

    Overview: Submitted a concept proposal for a GPS-denied autonomous quadrotor UAV system designed for indoor navigation and surveillance. The system focuses on vision-based navigation and sensor fusion for robust localization.

    View Project & Technical Details

    Problem Statement: GPS signals are unavailable or unreliable in indoor environments, underground facilities, and urban canyons, making traditional UAV navigation impossible. Critical applications like search-and-rescue, surveillance, and inspection require autonomous flight in such environments.

    Solution: A vision-based autonomous navigation pipeline using OAK-D Pro stereo camera for depth perception and visual odometry, integrated with Pixhawk flight controller running ArduPilot firmware. Sensor fusion combines IMU, LiDAR/ultrasonic range sensors, and stereo vision for robust GPS-denied localization.

    Key Features:
    • GPS-denied autonomous navigation
    • Stereo vision-based localization
    • SLAM mapping for indoor environments
    • Pixhawk + ArduPilot integration
    • Multi-sensor fusion framework
    Technical Details:
    • Vision-Based Navigation: OAK-D Pro stereo camera system providing depth perception, visual odometry, and obstacle detection.
    • Flight Control Architecture: Pixhawk flight controller with companion computer running ArduPilot firmware, enabling advanced autonomous flight modes and mission planning.
    • Sensor Fusion Framework: Multi-sensor integration combining IMU, LiDAR/ultrasonic range sensors, and stereo vision using SLAM algorithms for precise localization and mapping.
    • System Integration: Hardware integration strategy including power distribution, communication protocols (MAVLink), and real-time data processing for mission-critical operations.

    Impact: Submitted innovative concept proposal to ISRO's national robotics challenge, demonstrating advanced understanding of autonomous systems, computer vision, and GPS-denied navigation techniques.

    Generative Design: Mars Rover Chassis

    Design Lead. Engineered a mass-optimized 6-wheeled rover suspension system using Autodesk Fusion's generative design capabilities to maximize the strength-to-weight ratio for extraterrestrial exploration.

    View Project & Technical Details

    Problem Statement: Excess mass in planetary rovers exponentially increases launch costs. Traditional structural components are often over-engineered and lack organic load-path optimization.

    Solution: Applied generative design to a classic Rocker-Bogie kinematic model. By defining strict preserve regions for the DC motor mounts and central shafts, alongside specific load cases and obstacle geometries, the algorithm generated an organic, lattice-like structural chassis. This approach drastically reduces weight while maintaining strict structural integrity for traversing dynamic, uneven terrain.

    Key Features:
    • Generative design structural optimization
    • 6-Wheel Rocker-Bogie kinematics integration
    • Precise definition of preserve and obstacle geometries
    • Mass reduction targeting aerospace payload constraints
